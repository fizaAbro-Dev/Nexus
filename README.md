# Nexus – Investor & Entrepreneur Collaboration Platform

Nexus is a React-based collaboration platform designed to connect investors and entrepreneurs. The platform provides communication, scheduling, document handling, payments, and security features in one place.

## Live Demo
🌐 https://nexus-beta-vert.vercel.app

## GitHub Repository
🔗 https://github.com/fizaAbro-Dev/Nexus

## Features

### Authentication & Security
- User Login & Registration
- Role-based dashboards
- Password security features
- 2FA OTP mockup

### Dashboard
- Entrepreneur Dashboard
- Investor Dashboard
- Profile Management

### Meeting & Scheduling
- Meeting Calendar
- Availability scheduling
- Meeting management

### Communication
- Real-time chat interface
- Video calling UI
- Audio/video controls

### Document Chamber
- Upload & preview documents
- E-signature support
- Deal/document status tracking

### Payment System
- Wallet balance display
- Deposit / Withdraw / Transfer simulation
- Transaction history

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Vercel

## Installation

Clone repository:

```bash
git clone https://github.com/fizaAbro-Dev/Nexus.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
